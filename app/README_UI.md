# FoodGuard AI Mobile-First UI

Copy `components/ui.py` to `C:\FoodGuard_AI\app\components\ui.py` and `app.py` to `C:\FoodGuard_AI\app\app.py`.

Keep both `components/__init__.py` and `views/__init__.py` blank.

Run from `C:\FoodGuard_AI`:

```bash
streamlit run app/app.py
```

The redesign keeps your existing ML/OCR/diary view functions and changes the presentation layer. It uses inline SVG icons, so no icon package is required.
